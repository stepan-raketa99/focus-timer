# Focus Timer

Локальный секундомер для учебных сессий. HTML, CSS и JavaScript без внешних библиотек, регистрации и сетевых сервисов.

## Локальный запуск

Нужен Python 3 для статической раздачи файлов. В каталоге проекта выполните:

```sh
python -m http.server 8000 --bind 127.0.0.1
```

Откройте **http://127.0.0.1:8000/** в Google Chrome. Интернет не нужен. Команда только раздаёт статические файлы на localhost: прикладного сервера и API нет. Остановка — Ctrl+C в терминале. Используйте один и тот же адрес и порт, чтобы видеть ранее сохранённую историю.

Открытие `index.html` через `file://` не поддерживается: браузер ограничивает загрузку ES-модулей.

## Автоматические проверки

Нужен Node.js 22 или новее (проверено на Node.js 26). Устанавливать пакеты не требуется. Запуск из каталога проекта:

```sh
node --test
```

## Управление секундомером

При загрузке выбрана цель 60 минут; до старта доступны также 30 и 5 минут.
«Старт» запускает отсчёт с нуля, «Пауза» замораживает активное время,
«Продолжить» возобновляет отсчёт без длительности паузы. Во время работы
и паузы смена цели запрещена. Время показывается как ЧЧ:ММ:СС с округлением
секунд вниз, часы не оборачиваются после суток.

Прогресс ограничен 100%, но достижение цели не останавливает и не сохраняет
сессию. «Завершить» доступно во время работы и паузы: только активная
длительность не меньше цели даёт успешный результат. Сравнение выполняется
в миллисекундах до округления. При любом завершении время и прогресс
сбрасываются, выбранная цель сохраняется и снова доступна для изменения.

Активная сессия после перезагрузки не восстанавливается. Отсчёт вычисляется
по абсолютным меткам времени, поэтому задержки обновления вкладки не теряют
время. Перевод системных часов влияет на результат; отрицательная разница
ограничивается нулём. Приложение рассчитано на одну активную вкладку:
синхронизации между вкладками нет.

## История и границы хранения

Ключ localStorage — `focus-timer.history.v1`. Формат JSON:
`{ "version": 1, "sessions": [...] }`. Каждая запись содержит `id`,
`startedAt` и `endedAt` (временные метки в миллисекундах), `date` (локальная
дата завершения `YYYY-MM-DD`), `targetMs`, `activeMs` и `tasks`.
Задача в снимке содержит `id`, `title` и булево `completed`.
Сохраняются только успешные вручную завершённые сессии с фактическим
активным временем без пауз, включая превышение цели.

«Сегодня» показывает записи по локальной дате завершения, новые сверху,
их количество и сумму активного времени. Сессия, начатая вчера и завершённая
сегодня, целиком относится к сегодняшнему дню. Старые записи остаются
в хранилище. Без записей итоги равны 0 и 00:00:00.

История привязана к браузеру и адресу страницы; очистка данных браузера
удаляет её. После перезагрузки восстанавливается только успешно записанная
история. Незавершённая сессия, её задачи, выбранная цель и режим концентрации
не сохраняются. Несколько вкладок могут перезаписать историю друг друга.

При ошибке чтения, повреждённом JSON или неверной структуре приложение
показывает сообщение об ошибке восстановления и начинает с пустой
истории. Ошибка записи не отменяет завершение: таймер сбрасывается, текущие
задачи очищаются, результат остаётся видимым в памяти. Сообщение сообщает,
что сохранность результата после перезагрузки не гарантирована.

## Задачи и концентрация

Задачи можно добавлять, отмечать, снимать отметку и удалять до старта,
во время работы и на паузе. Пробелы по краям названия обрезаются; одинаковые
названия разрешены. После любого завершения список очищается. При успешном
завершении история получает независимый снимок названий и статусов.

«Концентрация» скрывает заголовок, выбор цели, статистику и второстепенные
подписи. Таймер, прогресс, задачи и управление остаются доступны. Включение
и выключение не меняют состояние сессии. Кнопка «Выйти из концентрации»
всегда доступна внутри этого режима.

Полный экран включается только отдельной кнопкой «На весь экран».
«Остаться в окне» закрывает предложение, сохраняя концентрацию.
Отказ браузера или отсутствие Fullscreen API показывают встроенное сообщение;
концентрация продолжает работать в окне. Escape выходит только из полного
экрана. Выход из концентрации также запрашивает выход из fullscreen;
при отказе можно воспользоваться Escape или меню браузера.

`tests/app.test.mjs` использует небольшой подставной DOM и API без сторонних

поведения разрешений fullscreen.

Последний автоматический прогон на Node.js v26.13.0: **19 тестов прошли,

в новом DOM). Синтаксис всех шести `.mjs`-файлов проверен через `node --check`.
Изменение прошло `openspec validate focus-timer --strict`.
Ручные браузерные результаты этим прогоном не подтверждаются.

Проверка синтаксиса (PowerShell):

```powershell
foreach ($file in @('app.mjs', 'domain.mjs', 'storage.mjs', 'tests/app.test.mjs', 'tests/domain.test.mjs', 'tests/storage.test.mjs')) {
  node --check $file
  if ($LASTEXITCODE -ne 0) { exit $LASTEXITCODE }
}
```

## Ручной чек-лист браузера

Все пункты ниже **ожидают вашей проверки**. Запишите браузер и его версию,
ОС, дату, размер окна и фактический результат в таблицу в конце раздела.
Используйте одну вкладку и тестовый профиль браузера для опытов с хранилищем.
Запустите сервер командой выше и откройте http://127.0.0.1:8000/.

### А. Режимы — T1, пункт 5.1

- [ ] После загрузки выбран режим 60 минут, таймер 00:00:00, прогресс 0%, завершение недоступно.
- [ ] До старта переключаются 60/30/5 минут, подпись цели соответствует выбору.
- [ ] После старта режимы недоступны мышью и клавиатурой; на паузе тоже.
- [ ] После завершения выбор вновь доступен, последняя цель сохранена.
- [ ] После перезагрузки выбрана цель 60 минут.

### Б. Время, пауза и возврат вкладки — T2, пункт 5.1

- [ ] Старт запускает отсчёт; после 59 секунд отображается 00:01:00.
- [ ] На паузе значение не меняется; продолжение исключает время паузы. Повторите паузу дважды.
- [ ] Оставьте работающий таймер в фоновой вкладке на 1–2 минуты. После возврата он учитывает весь активный интервал.
- [ ] На паузе выполните тот же опыт: время остаётся прежним.
- [ ] Во время отсчёта вводите длинное название задачи: текст, курсор и фокус не сбрасываются.

### В. Прогресс — T3, пункт 5.1

- [ ] Выберите 30 минут. Через 15 активных минут прогресс 50%.
- [ ] Через 35 активных минут время 00:35:00, прогресс 100%, кнопка остаётся «Пауза», история ещё не пополнилась.

Для ускоренного опыта в отдельной тестовой вкладке можно управлять часами
приложения из DevTools Console (системные часы не меняются):

```js
window.testNow = Date.now();
Date.now = () => window.testNow;
```

После этого выберите цель и нажмите «Старт». Выполните
`window.testNow += 15 * 60_000`, подождите обновления; затем
`window.testNow += 20 * 60_000`. Получатся точки 15 и 35 минут.
На паузе сдвигайте часы тем же способом — активное время не должно расти.
Перезагрузка страницы отменяет подмену. Этот опыт проверяет пересчёт, но
не заменяет реальную проверку фоновой вкладки и хода часов из раздела Б.

### Г. Завершение — T4, пункты 5.1, 5.3

- [ ] Цель 5 минут, завершение раньше цели: таймер/прогресс обнулены, задачи очищены, количество и история не изменились.
- [ ] Ровно 5 минут и вручную «Завершить»: добавляется одна запись. Для точной границы используйте подмену часов выше.
- [ ] Повторите с 5 минутами минус 1 мс: запись не добавляется.
- [ ] При превышении цели сохраняется фактическая длительность, не значение цели.
- [ ] Повторите успешное и досрочное завершение на паузе после долгого сдвига часов: последняя пауза не учитывается.
- [ ] После завершения кнопка недоступна; повторный клик не добавляет запись.

### Д. Задачи и история — T5, пункты 5.2, 5.3, 7.2

- [ ] Пустая строка и только пробелы не добавляются; показано сообщение или стандартная проверка обязательного поля.
- [ ] Добавьте две задачи с одинаковым названием, отметьте одну, снимите отметку, удалите другую: действия независимы.
- [ ] Повторите добавление, отметку и удаление до старта, во время работы и на паузе.
- [ ] Добавьте `<img src=x onerror=alert(1)>`: виден буквальный текст, изображение и всплывающее окно не появляются.
- [ ] Завершите успешную сессию с выполненной и невыполненной задачами: текущий список пуст; история содержит оба названия и статуса, интервал ЧЧ:ММ–ЧЧ:ММ и фактическую длительность.
- [ ] Измените задачи следующей сессии: предыдущая запись не меняется.
- [ ] Перезагрузите страницу: история восстановлена, текущая сессия и её задачи не восстановлены.
- [ ] Сквозной сценарий: задачи → старт с целью 30 минут → 15 минут → пауза 3 минуты → продолжение 20 минут → ручное завершение → перезагрузка. Результат: 35 минут активности, 38 минут между началом и концом, один снимок задач.
- [ ] Затем завершите следующую сессию досрочно: история предыдущей не изменилась, текущие задачи очищены.

### Е. Сегодня и полночь — пункт 5.3

- [ ] Две сегодняшние сессии 35 и 60 минут дают количество 2 и 01:35:00; новые записи сверху.
- [ ] Вчерашняя запись не отображается сегодня, но остаётся в localStorage.
- [ ] Для проверки полуночи задайте `window.testNow = new Date(2026, 10, 14, 23, 58).getTime()` при подменённых часах. Начните с целью 5 минут, прибавьте 5 минут и завершите: вся сессия относится к 15 ноября.
- [ ] Переведите тестовые часы на следующую местную дату: на очередном обновлении «Сегодня» пересчитывается без перезагрузки. Повторите при уходе и возврате вкладки.
- [ ] День без результатов показывает 0, 00:00:00 и пустую историю.

### Ж. Ошибки localStorage — пункт 5.3

Выполняйте в тестовом профиле: изменение ключа затрагивает его историю.

- [ ] В Console выполните `localStorage.setItem('focus-timer.history.v1', '{')` и перезагрузите. Показано сообщение восстановления, история пустая, таймер и задачи работают.
- [ ] Повторите с `localStorage.setItem('focus-timer.history.v1', '{"version":2,"sessions":[]}')`: неизвестная версия отвергается.
- [ ] Для отказа записи после загрузки выполните `Storage.prototype.setItem = function () { throw new DOMException('Тест', 'QuotaExceededError'); }`. Успешно завершите 5-минутную сессию: запись видна в памяти, таймер и задачи сброшены, показано сообщение о возможной потере результата.
- [ ] Повторное нажатие «Завершить» не дублирует результат. Перезагрузка снимает подмену и восстанавливает только ранее записанную историю.
- [ ] Для реального запрета чтения заблокируйте хранение данных сайта настройками браузера и перезагрузите: приложение остаётся работоспособным, показывает ошибку восстановления. Если браузер не позволяет такой режим, запишите «недоступно» и его версию.

### З. Ширина 390 пикселей, клавиатура и офлайн — пункты 5.4, 7.3

- [ ] Установите ширину viewport 390 CSS-пикселей в DevTools. Добавьте длинное название без пробелов (например, 200 букв) и сохраните его в истории.
- [ ] Нет горизонтальной прокрутки, длинный текст переносится, все кнопки и итоговое время помещаются. В Console `document.documentElement.scrollWidth <= window.innerWidth` возвращает `true`.
- [ ] Только клавиатурой (Tab, Shift+Tab, стрелки для режимов, Space, Enter) выполните выбор цели, старт/паузу/продолжение, добавление/отметку/удаление задачи, завершение, вход/выход из концентрации. Фокус видим; после удаления задачи и завершения не теряется.
- [ ] Отключите интернет, оставив локальный сервер работающим. Перезагрузите страницу: модули и стили загружаются, функции работают. Режим Offline в DevTools может блокировать и localhost — используйте отключение внешней сети.
- [ ] В Network после перезагрузки только запросы к `127.0.0.1:8000`, нет внешних шрифтов, библиотек, API; в Console нет ошибок. Нет рекламы и отвлекающих анимаций.

### И. Концентрация и fullscreen — пункты 6.1, 6.2, 7.3

- [ ] В idle, running и paused включите/выключите концентрацию: задачи и состояние таймера сохранены, статистика/режимы скрываются и возвращаются.
- [ ] В концентрации видны таймер, прогресс, задачи, необходимые кнопки и «Выйти из концентрации»; проверьте также ширину 390 пикселей.
- [ ] «Остаться в окне» скрывает предложение, но оставляет концентрацию. После выхода и повторного входа предложение доступно снова.
- [ ] «На весь экран» по клику включает fullscreen, кнопка выхода видна. Escape возвращает окно, но концентрация и сессия остаются в прежнем состоянии.
- [ ] Войдите в fullscreen снова и выйдите кнопкой концентрации: обычный интерфейс и оконный режим восстановлены.
- [ ] Для воспроизводимого отказа в Console задайте `document.documentElement.requestFullscreen = () => Promise.reject(new Error('Тестовый отказ'))`. Нажмите кнопку fullscreen: есть сообщение, концентрация и таймер продолжают работать.
- [ ] Для отсутствующего API после перезагрузки задайте `document.documentElement.requestFullscreen = undefined`. Повторите: режим работает в окне. Также проверьте браузер без API, если он доступен, и запишите его версию.
- [ ] Перезагрузите страницу, чтобы отменить подмены. Повторите выход из fullscreen на паузе: отсчёт не возобновляется сам.
