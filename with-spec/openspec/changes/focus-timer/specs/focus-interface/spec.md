# Spec Delta

## Purpose

Предоставить спокойный интерфейс для локальной учебной работы, удобный на мобильном экране и поддерживающий глубокую концентрацию.

## ADDED Requirements

### Requirement: Локальный адаптивный интерфейс
Приложение SHALL работать в браузере без интернета, регистрации, API-ключей и внешних сетевых ресурсов. Русскоязычный интерфейс SHALL помещаться в ширину 390 пикселей без горизонтальной прокрутки и не содержать рекламу, отвлекающие анимации и лишние уведомления.

#### Scenario: Узкий экран
- **WHEN** пользователь открывает приложение при ширине 390 пикселей и добавляет задачу с длинным названием
- **THEN** элементы управления, задачи и история доступны без горизонтальной прокрутки

#### Scenario: Работа без интернета
- **WHEN** локальные файлы приложения доступны браузеру, а интернет отключён
- **THEN** таймер, задачи, статистика и режим концентрации работают без внешних запросов

### Requirement: Глубокая концентрация
Пользователь SHALL иметь возможность включить и выключить режим глубокой концентрации в любой момент. В этом режиме SHALL оставаться только секундомер, прогресс, задачи и необходимые кнопки управления, включая выход; статистика, настройки и второстепенные элементы SHALL скрываться без изменения состояния сессии.

#### Scenario: Включение во время работы
- **WHEN** пользователь включает глубокую концентрацию во время сессии
- **THEN** второстепенные элементы скрыты, а секундомер и задачи сохраняют своё состояние

#### Scenario: Выход на паузе
- **WHEN** пользователь выходит из глубокой концентрации на паузе
- **THEN** обычный интерфейс восстановлен и сессия остаётся на паузе

### Requirement: Добровольное полноэкранное отображение
При включении глубокой концентрации приложение SHALL предлагать перейти в полноэкранный режим браузера по действию пользователя. Отказ или отсутствие поддержки SHALL оставлять режим концентрации доступным. Выход из полноэкранного отображения SHALL не останавливать и не завершать сессию.

#### Scenario: Принятие предложения
- **WHEN** пользователь выбирает полноэкранное отображение и браузер разрешает запрос
- **THEN** приложение занимает полный экран с доступной кнопкой выхода из концентрации

#### Scenario: Отказ или неподдерживаемый API
- **WHEN** пользователь отклоняет предложение либо браузер не поддерживает или отклоняет полноэкранный запрос
- **THEN** глубокая концентрация продолжает работать в обычном окне

#### Scenario: Выход клавишей Escape
- **WHEN** пользователь выходит из полноэкранного отображения клавишей Escape
- **THEN** сессия продолжается в прежнем состоянии, режим концентрации остаётся включённым и его кнопка выхода доступна
