# Spec Delta

## Purpose

Позволить пользователю вести задачи текущего занятия и сохранять их итоговые статусы в истории успешной учебной сессии.

## ADDED Requirements

### Requirement: Управление задачами
Приложение SHALL позволять добавлять задачи с названием, переключать статус выполнения и удалять задачи до старта, во время работы и на паузе. Новая задача SHALL иметь статус «не выполнена». Пустое или состоящее только из пробелов название SHALL отклоняться.

#### Scenario: Добавление и изменение статуса
- **WHEN** пользователь добавляет задачу «Прочитать главу» и отмечает её выполненной
- **THEN** задача появляется сначала невыполненной, а затем выполненной; пользователь может снять отметку

#### Scenario: Некорректное название
- **WHEN** пользователь пытается добавить пустое название или только пробелы
- **THEN** новая задача не появляется

#### Scenario: Работа с задачами на паузе
- **WHEN** сессия приостановлена и пользователь добавляет, отмечает или удаляет задачу
- **THEN** список отражает действие, остаётся доступным для просмотра, а секундомер остаётся на паузе

### Requirement: Очистка и снимок задач
При любом ручном завершении сессии приложение SHALL очищать текущие задачи. При успешном завершении приложение SHALL предварительно включать названия и статусы всех оставшихся задач в независимый снимок истории сессии.

#### Scenario: Успешная сессия
- **WHEN** пользователь завершает успешную сессию с выполненной и невыполненной задачами
- **THEN** текущий список пуст, а обе задачи с итоговыми статусами доступны в истории

#### Scenario: Досрочное завершение
- **WHEN** пользователь завершает сессию раньше цели
- **THEN** текущий список пуст и история сессии с задачами не создаётся

#### Scenario: Независимость истории
- **WHEN** пользователь добавляет и изменяет задачи следующей сессии
- **THEN** задачи ранее сохранённой сессии не изменяются
