# Proposal

## Why

Для учебной концентрации нужен простой локальный инструмент, который учитывает фактическое время работы и сохраняет результаты без регистрации и интернета. `brief.md` задаёт требования, но приложение и автоматические проверки пока отсутствуют.

## What Changes

- Добавить секундомер с целями 60, 30 и 5 минут, паузой, продолжением, ручным завершением и ограниченным до 100% прогрессом.
- Добавить задачи текущей сессии с отметками выполнения и очисткой после завершения.
- Сохранять только успешные вручную завершённые сессии в localStorage; показывать сегодняшнюю историю, количество и фактическую длительность без пауз.
- Добавить режим глубокой концентрации с предложением полноэкранного отображения и доступным выходом.
- Создать адаптивный русскоязычный интерфейс на HTML, CSS и JavaScript без внешних библиотек; выделить расчёты в `domain.mjs` и проверить их через `node:test`.
- За рамками: сервер, аккаунты, синхронизация, произвольные цели, автоматическое завершение, уведомления, восстановление незавершённой сессии после перезагрузки.

## Capabilities

### New Capabilities

- `session-timer`: жизненный цикл секундомера, режимы, активное время и прогресс.
- `session-tasks`: управление задачами текущей сессии и снимок задач при завершении.
- `session-statistics`: сохранение успешных сессий и статистика по локальной дате завершения.
- `focus-interface`: локальный адаптивный интерфейс и режим глубокой концентрации.

### Modified Capabilities

Нет: существующие спецификации отсутствуют.

## Impact

Проект начинается с `brief.md` и конфигурации OpenSpec; исходный код, тесты и настройки сборки отсутствуют. Потребуются статическая страница, стили, клиентские модули, модуль `domain.mjs`, тесты встроенного Node.js и инструкция локального запуска. Внешние API и зависимости не нужны; используются браузерные localStorage и Fullscreen API. Основные спецификации будут добавлены при последующей синхронизации изменения.
