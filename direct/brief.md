# Focus Timer

## 1. Цель
Веб-приложение для концентрации во время учёбы.

## 2. Функциональные требования

### Таймер
Таймер работает как секундомер: при нажатии кнопки «Старт» отсчёт начинается с 00:00:00 и увеличивается с течением времени.

Время отображается в формате ЧЧ:ММ:СС. После 59 секунд происходит переход к следующей минуте, после 59 минут — к следующему часу.

При нажатии кнопки «Пауза» отсчёт останавливается. При нажатии кнопки «Продолжить» отсчёт возобновляется с сохранённого значения.

Пользователь может выбрать целевую длительность сессии. При достижении цели секундомер не останавливается, а продолжает отсчитывать время до ручного завершения.

Прогресс текущей сессии рассчитывается по формуле:

Прогресс (%) = (прошедшее время в секундах / целевое время в секундах) × 100

Отображаемый прогресс не превышает 100%, даже если пользователь занимается дольше запланированного.

При нажатии кнопки «Завершить» секундомер останавливается, сбрасывается до 00:00:00 и переходит в исходное состояние.

Сессия считается успешно завершённой и сохраняется в статистике только в том случае, если фактическая длительность занятия не меньше выбранной целевой длительности. Если пользователь завершил сессию раньше, она не засчитывается и не сохраняется.

В статистике сохраняется фактическая длительность занятия, даже если она превышает выбранную цель.

Для точности секундомер должен учитывать реально прошедшее время, а не только количество срабатываний обновления интерфейса.

### Режимы
Доступны три режима с целевой длительностью 01:00:00, 00:30:00 и 00:05:00

Выбранный режим определяет целевую длительность сессии.

По достижении цели секундомер продолжает работать до ручного завершения.

Переключать режим разрешается только до начала сессии или после её завершения. Во время работы или паузы переключение недоступно.

По умолчанию выбран режим 01:00:00.

### Задачи
Пользователь может добавлять задачи на текущую учебную сессию.

Каждая задача содержит название и статус: выполнена или не выполнена.

Пользователь может отмечать задачи выполненными и удалять их.

Нельзя добавить задачу с пустым названием или названием, состоящим только из пробелов.

После завершения сессии все задачи автоматически удаляются, независимо от того, была ли достигнута целевая длительность.

Во время паузы задачи остаются доступными для просмотра и редактирования.

### Статистика
Приложение отображает статистику учебных сессий за сегодняшний день.

Показываются количество успешно завершённых сессий и суммарное фактическое время концентрации.

Для каждой успешной сессии отображаются:

время начала и окончания в формате ЧЧ:ММ–ЧЧ:ММ;

фактическая длительность занятия без учёта пауз;

названия задач с отметками выполнения.

Сессия сохраняется только при достижении целевой длительности и ручном завершении.

После завершения текущие задачи очищаются, но остаются в истории успешной сессии.

Статистика сохраняется в localStorage.

В разделе «Сегодня» отображаются только сессии, завершённые за текущую дату.

Суммарное время концентрации рассчитывается по фактической длительности успешных сессий.

### Режим глубокой концентрации
Пользователь может включить и выключить режим глубокой концентрации.

В этом режиме отображаются только секундомер, прогресс, задачи текущей сессии и необходимые кнопки управления.

Статистика, настройки и остальные второстепенные элементы скрываются.

При включении режима приложение предлагает перейти в полноэкранный режим браузера.

Пользователь может в любой момент выйти из режима концентрации.

В интерфейсе отсутствуют реклама, отвлекающие анимации и лишние уведомления.

## 3. Ограничения
Приложение работает локально в браузере.

Используются HTML, CSS и JavaScript без внешних библиотек и серверной части.

Приложение не требует регистрации, интернета или API-ключей.

Интерфейс должен корректно отображаться на экране шириной 390 пикселей без горизонтальной прокрутки.

Расчёты времени, прогресса и проверка условий завершения сессии должны быть вынесены в отдельный модуль domain.mjs.

Автоматические тесты создаются с помощью встроенного node:test.

## 4. Критерии приёмки
T1. Режимы: доступны цели 60, 30 и 5 минут. По умолчанию выбрано 60 минут. Во время работы секундомера и паузы смена режима запрещена.

T2. Секундомер: после запуска время увеличивается. Во время паузы не увеличивается. После продолжения отсчёт возобновляется без учёта времени паузы.

T3. Прогресс: при цели 30 минут через 15 минут активной работы прогресс равен 50%. Через 35 минут — 100%, но секундомер продолжает работать.

T4. Завершение: при завершении раньше цели сессия не сохраняется. При достижении цели и ручном завершении сессия сохраняется с фактической длительностью. Секундомер сбрасывается.

T5. Задачи и статистика: пользователь может добавлять, выполнять и удалять задачи. После завершения сессии текущие задачи очищаются. Для успешной сессии в истории сохраняются время начала, время окончания и список задач с их статусами.

### Дизайн Focus Timer

- Тёмная тема с минималистичной эстетикой Apple.
- Почти чёрный фон (`#080B12`), тёмные поверхности (`#121A2B`).
- Основной акцент — глубокий синий (`#1D4ED8`), с более яркими синими оттенками для активных состояний.
- Крупный секундомер в центре внимания.
- Большие, удобные кнопки управления.
- Плавные, ненавязчивые анимации кнопок, переходов и прогресса.
- Аккуратная типографика, скруглённые элементы, достаточно свободного пространства.
- Адаптация под смартфоны шириной 390 CSS-пикселей без горизонтальной прокрутки.
